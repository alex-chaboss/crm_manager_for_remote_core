# Контракт кастомного `project-widget`

Динамическая загрузка произвольного Python из каталога **`Projects/<id>/project-widget/`** выполняется на машине пользователя и несёт те же риски, что и запуск любого локального кода. Ознакомьтесь с **[DISCLAIMER.md](../DISCLAIMER.md)** в корне репозитория.

## Что именно подменяется

Виджет из `project-widget/` занимает **всю область выбранного проекта** (контент под строкой вкладок `simple_game | simple_service | …`). Строка вкладок **по проектам**, кнопка **⚙** на вкладке и левая глобальная панель **не** подменяются.

- При **успешной** загрузке кастома **нет** встроенных у ядра вкладок «Метрики» и «Health» — только то, что вернул ваш `build` или класс **`CRMProjectTab`**.
- При **ошибке** загрузки CRM подставляет **`LegacyProjectTabsWidget`**: подсказка про ⚙ и вкладки **Метрики** / **Health** (заглушки).

## Деплой и настройки

Все операции **Clone**, **Init на сервере**, **Деплой**, SSH-списки команд и пути — только через **модальное окно ⚙** на вкладке проекта ([`ProjectSettingsDialog`](../crm/gui/project_settings_dialog.py)). Кастомный виджет может показать [`ProjectSettingsHint`](../crm/gui/project_settings_hint.py) или свой текст, но **не должен** дублировать полный пайплайн без согласования с `config_store`.

Длительные операции идут через **`OperationRunner`** + **`OperationLogDialog`** (лог, Стоп, блокировка главного окна).

## Зарезервированные имена

| Элемент | Значение |
|--------|----------|
| Каталог | `Projects/<id>/project-widget/` |
| Файл | **`base_project_widget.py`** (`crm.project_widget_loader.RESERVED_WIDGET_FILE`) |
| Функция (приоритет 1) | **`build`** (`ENTRYPOINT_NAME`) |
| Класс (приоритет 2) | **`CRMProjectTab`** (`RESERVED_CLASS_NAME`) |

Если в модуле есть **и** вызываемый `build`, **и** класс `CRMProjectTab`, используется **`build`**.

## Сигнатура `build`

```text
build(parent: QWidget, project_id: str, main_window) -> QWidget
```

- **`parent`** — родитель: контейнер области проекта (`_ProjectInner`).
- **`project_id`** — идентификатор проекта (имя каталога в `Projects/`).
- **`main_window`** — `MainWindow`: `open_project_settings(project_id)`, тосты, прогресс, `current_locale()` и т.д.

Возвращаемый **`QWidget`** — корень UI проекта (вкладки внутри, `QSplitter`, 3D, пустая панель — на усмотрение проекта).

## Сигнатура `CRMProjectTab`

Класс **`CRMProjectTab`** должен наследовать **`QWidget`** и поддерживать конструктор:

```text
CRMProjectTab(project_id: str, main_window, parent=None)
```

`main_window` — тот же экземпляр, что и в `build`.

## Поведение при ошибке

При отсутствии файла, ошибке импорта/исполнения, если `build` не вызываемый или вернул не `QWidget`, если нет пригодного класса `CRMProjectTab` или конструктор выбросил исключение — в лог пишется причина и показывается **`LegacyProjectTabsWidget`**.

## Интеграция SSH

Подсветка полей SSH при ошибке валидации — в **модалке ⚙** (`ProjectSettingsDialog.mark_ssh_field_error`). Область кастомного виджета методы `mark_ssh_field_error` / `clear_ssh_field_error` может реализовать пустыми или делегировать в свои поля, если вы сознательно дублируете SSH в кастоме (не рекомендуется).

## Локализация (текущая версия)

Переключение **ru/en** в CRM **не обязано** затрагивать кастомный виджет. При необходимости реализуйте у корня **`apply_language()`** — тогда `MainWindow.apply_language()` вызовет его при смене локали.

## Обязательно (согласованность с CRM)

- Не обходить **`config_store`** при изменении **`project_profile.json`**.
- Деплой и init — через ⚙ или тот же публичный API (`OperationRunner`), не блокировать GUI в **`build`** / **`__init__`**.

## Запрещено / не рекомендуется

- Импорт из чужих монолитов репозитория вне пакета `crm/` без контроля окружения.
- Выполнение кода из сети при открытии проекта без явного действия пользователя.
- Скрытие ⚙ или подмена деплоя без замены UX.

## Разрешено

- Любая визуальная структура внутри области проекта.
- Дополнительные модули в `project-widget/` и `import` соседних файлов (см. [project_widget_setup_and_git.md](project_widget_setup_and_git.md)).
